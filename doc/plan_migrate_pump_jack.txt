MIGRATION PLAN: PUMPJACK
========================
Source: elementalism/actors/PumpJack.txt + PumpJack.gl + models/PumpJack.txt
Target: zd_daf/ following conventions in context_migrating_models_from_elementalism.txt


OVERVIEW
--------
PumpJack is a large animated industrial oil pump with 80 MD3 keyframes spread across
4 sprite sequences. It has 7 separate surface skins (multi-surface MD3) and per-surface
normal + specular maps defined in GLDEFS.

Animation: PJKA A-Z + PJKB A-Z + PJKC A-Z + PJKD A (79 active frames, looping)
Scale: 50 50 50
No radius/height in original (commented out) -- needs values set during migration.
DoomEdNum in elementalism: 16053. Assign next available in zd_daf: 18041.

  If the MD3 embeds "models/skins/PumpJack/..." you may need to either:

  texture overrides (which is already done -- see GLDEFS section below).

  all 4 can be copies of the same 1x1 or minimal PNG.

1. ZScript actor -- add to zd_daf/actors/dungeon_props.zs

  class PumpJack : Actor {
      Default {
          //$Category "Models/Props"
          //$Title "Pump Jack"
          Radius 64;
          Height 128;
          -SOLID
          +NOGRAVITY
      }
      States {
          Spawn:
              PJKA ABCDEFGHIJKLMNOPQRSTUVWXYZ 2;
              PJKB ABCDEFGHIJKLMNOPQRSTUVWXYZ 2;
              PJKC ABCDEFGHIJKLMNOPQRSTUVWXYZ 2;
              PJKD A 2;
              Loop;
      }
  }

  NOTE: Radius/Height are guesses based on Scale 50 -- adjust after visual check.
  Elementalism had these commented out (//radius 2000 //height 700), suggesting
  the original author intended -SOLID with no collision, which is kept here.

3. GLDEFS material file -- create zd_daf/actors/pump_jack.gl
   Then add  #include "actors/pump_jack.gl"  under "// Models" in zd_daf/GLDEFS.

  Content -- translate from elementalism/actors/PumpJack.gl, updating paths:

  material texture "models/skins/pumpjack/walking_beam.png"
  {
      normal "materials/normalmaps/walking_beam_norm.png"
      specular "materials/specularmaps/spec_thing.png"
      specularlevel 0.5
      glossiness 1.0
      disablefullbright
  }
  ... (repeat for each of the 7 surfaces)

  Path changes from elementalism -> zd_daf:
    "models/skins/pumpjack/..."          ->  "models/skins/pumpjack/..."
    "materials/normalmaps/..."           ->  "materials/normalmaps/..."  (same)
    "materials/specularmaps/spec_thing"  ->  "materials/specularmaps/spec_thing.png"

  NOTE: zd_daf does not currently have a materials/ folder. Create it.
  The GLDEFS material blocks are purely additive/visual -- omitting them gives
  flat shading only, which is acceptable for an initial migration.

KNOWN ANOMALIES IN SOURCE (copy verbatim, do not fix)
------------------------------------------------------
- PJKA L -> frame 12 (frame 11 absent in source FrameIndex sequence)
- PJKB I and PJKB J both map to frame 35 (frame 36 skipped)
  These appear to be authoring bugs in elementalism. Copying verbatim preserves
  the original animation rhythm; correcting them would change the visual behaviour.


MIGRATION ORDER
---------------
1. Copy model file (Pumpjack.md3 -> pump_jack.md3)
2. Copy 7 skin PNGs into models/skins/pumpjack/
3. Copy 7 normal maps into materials/normalmaps/
4. Copy spec_thing.png into materials/specularmaps/
5. Copy PJKAA0.png to sprites/pump_jack/ and make 3 copies (PJKBA0, PJKCA0, PJKDA0)
6. Add ZScript class to actors/dungeon_props.zs
7. Add MODELDEF block to models/defs/dungeon_props.modeldef
8. Create actors/pump_jack.gl with GLDEFS material blocks
9. Add #include "actors/pump_jack.gl" to GLDEFS (under // Models)
10. Add DoomEdNum 18041 to MAPINFO
11. Load in UDB -- verify no sprite lump errors, verify model appears in thing browser
12. Test in GZDoom -- verify animation plays, skins render, normal/specular visible
